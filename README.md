Node.js Project Setup

1. mkdir project-name
2. cd project-name
3. npm init -y
4. touch index.js
5. npm install <package-name>
6. npm install -D <package-name>
7. node index.js

Git Setup:
1. git init
2. git add .
3. git commit -m "Initial project setup"
4. git branch -M main
5. git remote add origin <repository-url>
6. git push -u origin main
